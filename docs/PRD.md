## 2. 产品背景与目标

### 2.1 要解决的问题

**现状**：希望申请日本大学院社会学方向的学生，在选校、选导师、准备材料时面临大量分散信息。导师信息难以获取，套磁缺乏指导。

**机会**：通过构建一个轻量级平台，集成**导师库（研究标签+证据）**、**出愿日程**、**材料清单**，并提供**信息确认型套磁建议**，帮助学生完成从筛选到联系的关键步骤。

### 2.2 商业目标与成功指标

| 类型 | 目标 | 北极星指标 |
|------|------|------------|
| 必须解决 | 1. 用户能在平台内找到至少 3 位匹配研究兴趣的导师 | 周活跃导师查看数 |
| 必须解决 | 2. 覆盖 10-15 所上位校，每校 5 位导师 | （同上） |
| 锦上添花 | 1. 自动生成“套磁动作建议”卡片 | — |

### 2.3 用户价值

- **最终用户**：节省筛选导师的时间，获得可执行的套磁策略，降低申请不确定性。
- **维护者**：通过结构化数据和核验机制，持续提升信息可信度。

## 3. 假设与约束

### 3.1 技术约束
- 前端：静态 HTML/CSS/JS，无需后端。
- 数据存储：JSON 文件（导师库、出愿信息），通过 `fetch` 加载。
- 用户系统：V0 不做登录，使用本地存储记录用户偏好。
- 部署：GitHub Pages / Vercel / Netlify。

### 3.2 内容约束
- 覆盖研究科：东京大学人文社会系、东京大学综合文化、一桥大学社会学、早稻田大学社会科学（V0 基准）。
- 入试类型：仅“一般选拔”。
- 英文项目：不纳入 V0。

### 3.3 不考虑的场景

- 用户账户/登录系统
- 实时数据推送
- 导师库全量覆盖（每校只做 5 位种子导师）
- 套磁成功率分析

## 4. 用户画像与核心场景

### 场景 1：方向不明确的申请者
> 作为 **社会学本科学生，研究方向不明确**，  
> 我想要 **按标签（gender / 福祉 / media / culture）筛选导师**，  
> 以便 **快速找到与自己兴趣匹配的研究室**。

### 场景 2：已确定方向但缺乏套磁经验的申请者
> 作为 **已有研究计划的申请者**，  
> 我想要 **查看导师的“证据条目”和“接收信号”**，  
> 以便 **撰写有针对性、低风险的信息确认型套磁邮件**。

### 场景 3：同时管理多所学校申请的同学
> 作为 **多方向申请者**，  
> 我想要 **在一个页面上看到各校的出愿截止日和材料清单**，  
> 以便 **规划申请日程，避免错过DDL**。

## 5. 功能详细需求

### 5.1 首页设计

- **学校卡片网格**：每张卡片包含学校名称、研究科、出愿季（夏季/冬季）、已核验数据标记（✅）。
- **导师入口**：每个学校页面有“精选导师（5位）”区块，可展开查看导师详情。
- **官方入口链接**：募集要项页面、教员列表链接（供用户自助扩展）。

### 5.2 导师卡片（详情页）内容

| 字段 | 说明 |
|------|------|
| 姓名 | 中文为主，括号日文/罗马字 |
| 职称 | 教授/准教授/讲师/助教 |
| 研究标签 | 一级标签（Media / Gender / 社会福祉 / 文化 / 其他）+ 二级标签（最多3个） |
| 关键词 | 3-8个中文词 |
| 证据条目 | 至少1条（论文/项目/研究主题说明），附链接 |
| 接收信号 | “页面明确出现接收相关描述” / “页面未出现” / “信息不清楚” |
| 套磁建议 | 固定文案：“建议你联系去确认：今年是否接收修士/是否建议该主题报考” |

### 5.3 申请季管理

- 支持夏季与冬季双轨。
- 若募集要项未发布，显示上一年度日期并标注“参考往年，待更新”。

### 5.4 数据可信度标记

- 已核验数据（通过官方 PDF 核实）显示 ✅
- 未核验数据（来自 Perplexity 等知识库）显示 ⚠️ 待核验

## 6. 非功能需求

- **性能**：主页加载 ≤ 2 秒。
- **兼容性**：现代浏览器 + 移动端响应式。
- **数据维护**：导师数据每学期核验一次；用户上报触发即时复核。

## 7. 验收标准与成功指标

### 7.1 验收清单

- [ ] 首页展示 4 个研究科的学校卡片，区分核验状态。
- [ ] 每个学校下至少有 5 位导师（共 20+ 位）。
- [ ] 每位导师包含完整字段（标签、证据、接收信号、套磁建议）。
- [ ] 出愿截止日显示夏季/冬季双轨，未发布者标注“参考往年”。
- [ ] 点击“套磁建议”可复制预设邮件模板。
- [ ] 所有外部链接可打开。

### 7.2 北极星指标

**周活跃导师卡片查看数**（用户点击查看导师详情的次数）

## 8. 竞品参考与差异化

| 竞品 | 优势 | 劣势 |
|------|------|------|
| 探日 | 研究科介绍清晰 | 无导师标签和套磁指导 |
| 前程日本 | 引流服务 | 非纯工具，信息不透明 |

**差异化**：
- 导师研究标签 + 证据驱动
- 信息确认型套磁建议（降低沟通门槛）
- 开源数据核验机制
