## 追加条目 1 · Schema 修复

```markdown
- **mentors.json schema 修复(v0.3 → v0.4)**:基于 2026-05-01 的 35 条
  Perplexity 实测数据,发现 `url_homepage` 必填约束与现实不符——日本大学
  教员中只有 31% 维护个人主页。决定:`url_homepage` 改为可空(string|null);
  新增 `url_faculty_listing` 必填字段,作为"导师真实存在性"的最低验证锚点。
  保持 `url_homepage` 字段名的语义清洁(只表示"个人主页"),避免方案 C
  的语义污染。同步更新 PRD-mentors v0.4 + Perplexity 主提示词。(2026-05-01)
```
