## ✨ 核心亮点

- **🔍 导师研究标签体系**：按 gender / 福祉 / media / culture 分类，附证据链接，拒绝空泛推荐。
- **📅 双季申请日程**：支持夏季/冬季入试，未发布 DDL 标注“参考往年”。
- **💬 信息确认型套磁建议**：每导师固定文案 + 邮件模板，降低套磁心理负担。
- **✅ 数据可信度标记**：已核验数据 ✅ / 待核验 ⚠️，透明可追溯。
- **🧩 极简维护**：每校 5-10 位导师种子集 + 官方教员列表入口，不追求全覆盖。
