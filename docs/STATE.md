1. **先读 §-1**，确认你今天在做模块 A 还是模块 B

4. 粘进 agent
5. 让 agent **先复述它要做什么、读了哪份文档**，再开干

### 结束一次 agent 会话
让 agent 输出：

你贴回 STATE.md 对应区块 + 更新顶部时间戳。
